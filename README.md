# Brokenshire Hotel Management System (BHMS)

A comprehensive hotel management application developed as a major project for **Software Engineering 2**.

---

## 🏨 About the Project
The **Brokenshire Hotel Management System (BHMS)** was created with a clear mission in mind: **to reduce manual tasks and eliminate exhausting paperwork** traditionally required in hotel operations. 

By replacing physical logbooks and manual tracking with a streamlined digital system, BHMS optimizes day-to-day efficiency for hotel staff, secures data management, and creates a smoother experience for guests.

### 👥 Development Team
* **John Paul Domong-as** – UI Designer and Tester
* **Julie Anne A. Pesana** – Database Designer and System Analyst
* **Gabriel Joshua Regidor** – Software Engineer / Lead Developer

### ✨ Core Features & Objectives
* **Paperless Operations:** Digitizing guest records, room statuses, and transactions to minimize physical paperwork and clerical errors.
* **Workflow Automation:** Streamlining routine manual tasks for hotel administrators, receptionists, and staff.
* **Centralized Management:** Providing a single, cohesive dashboard to oversee hotel check-ins, check-outs, and availability.
